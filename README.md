# Pengembangan-Sistem-Data-Terintegrasi-untuk-Optimalisasi-Potensi-Desa-Cangkringan
Pengembangan sistem data terintegrasi berbasis website untuk analisis potensi bahan organik, pengelolaan produksi dan stok, prediksi permintaan pupuk organik, serta pemasaran produk Desa Cangkringan melalui data science.
