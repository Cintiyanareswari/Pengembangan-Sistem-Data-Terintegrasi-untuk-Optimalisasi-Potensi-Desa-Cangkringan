# Sistem Data Terintegrasi Desa Cangkringan

Sistem data terintegrasi berbasis website untuk mendukung optimalisasi potensi bahan organik, pengelolaan produksi dan stok, analisis data, serta pemasaran produk Desa Cangkringan.

## 📌 Tentang Proyek

Proyek ini merupakan bagian dari Program Mahasiswa Berdampak – Studi Independen 2026 yang berkolaborasi dengan PT Vinix Seven Aurum.

Desa Cangkringan memiliki potensi pengembangan produk pupuk organik dan probiotik. Namun, pengelolaan data bahan organik, produksi, stok, dan penjualan masih perlu diintegrasikan agar dapat dimanfaatkan secara optimal.

Oleh karena itu, proyek ini berfokus pada pengembangan sistem berbasis website yang mengintegrasikan pengelolaan data dan menyajikan hasil analisis sebagai informasi pendukung pengambilan keputusan.

## 🎯 Tujuan

- Mengintegrasikan data bahan organik, produksi, stok, dan penjualan dalam satu sistem.
- Mengidentifikasi potensi bahan organik berdasarkan ketersediaan, kontinuitas, jarak, dan kemudahan memperoleh bahan.
- Mendukung perencanaan produksi melalui analisis data dan prediksi permintaan pupuk organik.
- Menyediakan dashboard untuk memvisualisasikan informasi dan hasil analisis data.
- Mendukung pemasaran melalui katalog digital produk Desa Cangkringan.

## ✨ Fitur yang Direncanakan

- **Data Terintegrasi:** Pengelolaan data bahan organik, produksi, stok, penjualan, dan produk.
- **Dashboard Analitik:** Visualisasi data produksi, stok, dan penjualan.
- **Analisis Potensi Bahan Organik:** Penilaian dan pemeringkatan bahan organik menggunakan metode Weighted Sum Model (WSM).
- **Prediksi Permintaan:** Pengembangan model Machine Learning untuk memprediksi permintaan pupuk organik, menyesuaikan ketersediaan dan kualitas data.
- **Katalog Digital:** Penyajian informasi produk untuk membantu masyarakat dan calon konsumen mengenal produk desa.

## 🛠️ Teknologi

Teknologi yang direncanakan atau relevan untuk pengembangan proyek ini meliputi:

- **Python** — pengolahan dan analisis data.
- **SQL** — pengelolaan basis data.
- **Data Engineering** — pembersihan, transformasi, dan integrasi data.
- **Machine Learning** — pengembangan model prediksi jika data mencukupi.
- **Data Visualization** — penyajian informasi melalui dashboard.
- **Web Development** — integrasi data dan hasil analisis ke dalam website.

*Teknologi implementasi akhir akan disesuaikan dengan kebutuhan dan hasil pengembangan sistem.*

## 📊 Metodologi

1. Identifikasi kebutuhan mitra.
2. Pengumpulan dan pemeriksaan dataset.
3. Perancangan struktur database.
4. Data cleaning, preprocessing, dan integrasi data.
5. Analisis serta pemeringkatan potensi bahan organik.
6. Pengembangan dan evaluasi model prediksi jika data memungkinkan.
7. Integrasi hasil pengolahan ke dalam website.
8. Pengujian, deployment, dan dokumentasi.

## 🌱 Dampak yang Diharapkan

Sistem ini diharapkan dapat membantu Desa Cangkringan mengelola data secara lebih terstruktur, mengidentifikasi potensi bahan baku pupuk organik, mendukung perencanaan produksi, serta memperluas akses informasi produk melalui media digital.
